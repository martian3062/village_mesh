M3 - APPEARANCE / INTERIORS / WEATHER
Geographic sun uses installed Epic SunPosition library with the existing sun,
origin latitude/longitude, 2026-10-23 and UTC+05:30. No duplicate SunSky rig.
Shared wind m/s and artistic wetness/cloudiness state; wetting/drying response.
Rain suppression uses overhead visibility traces at the player. This is a
local shelter approximation, not spatial roof runoff, puddles or a Niagara
collision/splash implementation. Interior materials do not use global wetness.
Four repeatable conditions: daylight, evening, overcast and rain.
Three entrance, door-state-store and roof-shelter checks passed both in NullRHI
and in the rendered standalone package. State restoration after an actual
unload/reload cycle has not been separately exercised by this check.
Daylight was verified at physical sun elevation 43.08 degrees at 13:30 local.
The API's +180-degree light-rotation offset is removed exactly once.
All 32 final camera captures exist and are SHA256-indexed in evidence.json.
The fallback rain shell has faded edges and no visible cap band; it remains
an approximation and is not accepted as volumetric, collision-aware rain.

Playable render scale 67%, capture scale 100%, output 1440x900, uncapped FPS.
Route diagnostics record frame wall-time median/p95/p99/max after warmup and
peak process resident memory. CPU/GPU timing split and VRAM peaks are not

Three editor route trials: p95 10.94-12.40 ms; largest frame 93.72 ms.
Three final standalone trials: p95 10.98-13.13 ms; largest frame 31.43 ms.
These are offscreen D3D12/Epic local measurements on the recorded workstation.
119 HLOD actors built; overview inspected. Physics smoke: 13 finite simulating
bodies and grounded player at 96.06 cm. Its 1,880 instance count includes HLOD
instances and is not a vegetation count (base vegetation 146 + verge plants 128).
Continuous standalone soak passed: 1,800.026 wall-clock seconds after warmup,
31 route legs, 182,221 measured frames, no blocked/fall-through/crash failure.
Mixed-weather frame p95 12.71 ms, largest frame 62.10 ms, peak process resident
memory 1,546.1 MiB. This mixed-condition run is not another daylight trial.
Whole-adapter peak memory 4,297 MiB and GPU temperature 89 C include other
workloads. Interactive launchers now cap at 60 FPS; diagnostics remain uncapped.
The process-memory samples do not establish absence of all memory leaks.
